# Caesar Cipher 🔐

A collection of three beginner-level Caesar Cipher implementations using Python.

The Caesar Cipher is a simple encryption technique that shifts each letter in the alphabet by a specific number of positions.

## Versions

### Version 1 – Basic Console Version
- Encrypts and decrypts text.
- Uses a shift number.
- Runs in the terminal.

### Version 2 – Improved Console Version
- Supports spaces and non-alphabetic characters.
- Provides encryption and decryption options.
- Runs in the terminal.

### Version 3 – GUI Version
- Built with Tkinter.
- Provides a graphical interface.
- Allows users to enter text, direction, and shift amount.
- Displays the result in the application window.

## Technologies Used

- Python
- Tkinter
- Basic String Operations
- Functions and Loops

## How to Run

Make sure Python is installed.

```bash

```

```bash

```

```bash

```

## Notes

- Version 1 works with English alphabet letters only.
- Version 2 preserves spaces and non-alphabetic characters.
- Version 3 is a basic graphical implementation and currently expects alphabetic input without spaces.
